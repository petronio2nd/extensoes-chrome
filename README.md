## Ajudante do Windows do Downloads arrastáveis

O Downloads arrastáveis mostra os seus downloads recentes num painel do Windows, de onde dá para arrastar o arquivo até outro programa. Esse painel é um ajudante que se instala à parte, uma vez só.

1. Instale a extensão pelo link da Chrome Web Store.
2. [Baixe o ajudante (.zip)](https://github.com/petronio2nd/extensoes-chrome/releases/latest/download/downloads-arrastaveis-ajudante.zip).
3. Abra o arquivo baixado e extraia a pasta: botão direito > **Extrair tudo**.
4. Na pasta extraída, dê dois cliques em `instalar.cmd`. Se o Windows avisar que o arquivo veio da internet, clique em **Executar** (ou em **Mais informações** e depois em **Executar assim mesmo**).
5. Quando aparecer "instalado", volte ao Chrome e clique no ícone **Downloads arrastáveis**.

Só funciona no Windows. O ajudante roda no PowerShell que já vem no Windows, não pede administrador e não acessa a internet. Os scripts ficam dentro do .zip, para quem quiser conferir. Para tirar o ajudante, dê dois cliques em `desinstalar.cmd`, no mesmo .zip.

As versões ficam em [Releases](https://github.com/petronio2nd/extensoes-chrome/releases).
